# Amusnet-Hackathon

Open `My project/Assets/Scenes/Sprint2Workspace.unity` in Unity and press Play
to try the village. Use WASD to fly, Space to climb, and Left Shift to descend.
Fly through a laundry line or near the latch of a gate to start a chain. Either
can startle the local chicken, which runs into its pot. Each object scores once
per run. Press R to restart. The HUD shows recent point awards and stops the
timer when you reach the goal.

| Area | Objects and point values | Possible points |
| --- | --- | ---: |
| Flower trail | Gate (4), laundry (6), chicken (3), pot (7) | 20 |
| Village crossroads | Gate (4), laundry (6), chicken (3), pot (7) | 20 |
| Pond path | Laundry (6), chicken (3), pot (7) | 16 |
| Barn yard | Gate (4), laundry (6), chicken (3), pot (7), six hay bales (3 each) | 38 |
| North paddock | Gate (4), chicken (3), pot (7) | 14 |
| **Total** | **24 scoring objects** | **108** |

The current goal is 100 points and requires scoring in all five areas. An
automated clear-weather flight with known prop locations reached 101 points
in 49.6 seconds. The 15-minute target still needs human playtests with the
final flight controller and village difficulty.
