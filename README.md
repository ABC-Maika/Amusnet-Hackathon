# Amusnet-Hackathon

Open `My project/Assets/Scenes/Sprint3Village.unity` in Unity and press Play.
Use **WASD** to fly, **Space** to climb, **Left Shift** to descend, **Tab** to
view district progress, and **R** to restart. The first laundry line is ahead
at the Village Center. Approach props at their height.

This playtest scene uses the team's seven-section Village map. Every district
has a gate, a laundry line, a chicken, a pot, and two hay bales. Either the
gate or the laundry can startle the chicken, which runs into its pot. Scoring
an object once spends it for the run. A nearby villager can investigate the
disturbance, chase a visible butterfly, or complain after losing it.

| Object | Count | Points each | Total |
| --- | ---: | ---: | ---: |
| Gate | 7 | 4 | 28 |
| Laundry line | 7 | 6 | 42 |
| Chicken | 7 | 3 | 21 |
| Pot | 7 | 7 | 49 |
| Hay bale | 14 | 3 | 42 |
| **Total** | **42** | | **182** |

The goal is **160 points**. Each district offers 26 points, so the goal
requires a contribution from all seven districts. The run timer starts with
movement and stops at the goal. A scripted clear-weather route through all
seven districts reached the goal in **6:39** of game time. The 15-minute
target needs first-time player feedback on how long the chains take to find.

`Sprint2Workspace.unity` remains a smaller scene for testing interactions.
`Sprint3ModelReview.unity` shows the villager, animal, and prop prototypes.
